Methodology

This page explains where the data comes from, how it is cleaned and combined, and how each part of the prototype maps to the role.

This prototype uses account propensity and pool of funds to guide SA/FDE prioritization and resourcing. It flags upcoming opportunities and blockers, tracks active technical engagements, plans strategic onsites, turns repeated work into repeatable playbooks and a Professional Services package, and gives leadership a view of pipeline, engagement health, and investment ROI.

How the data flows

LayerFileWhat it holds
Rawdata/raw/accounts.csvOne extract of Salesforce fields and product usage per account (generated with a fixed seed, so every run matches)
Processeddata/processed/account_scores.csvEach customer in one row with score, pool of funds, flags, quadrant and rank
Outputdata/output/salesforce_writeback.csvThe fields we'd push back to Salesforce (GTM_*__c)
Sitedocs/data/accounts.jsonWhat every page on this site reads, so numbers match everywhere

How to read this: data moves top to bottom, like warehouse layers: raw extract, cleaned table, write-back to Salesforce, then the website.
